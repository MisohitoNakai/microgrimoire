微分音のグリモワール 第Ⅵ部 響きの科学

第Ⅵ部 響きの科学　─　7

音楽と脳 ── 統語・ERP・絶対音感

直感レイヤー

第Ⅵ部の締めくくりに、視点を耳から脳へ移します。
ここまでの「協和／不協和」は主に単発の響きの話でした。しかし音楽は時間の中の構造です。和音が連なり、期待が生まれ、裏切られ、解決する。この「音楽の文法」を脳がどう処理するかは、そっくりそのまま言語の文法処理と驚くほど似ています。
脳波（ERP）が捉える「和声の違反反応」と四分音の処理から始め、そこから音楽と言語は脳内で統語処理資源を共有するという仮説（SSIRH）へ、さらに生成文法と機能和声の対応、そして絶対音感の神経基盤までを一望します。これは 31edo のような新しい語彙と文法を脳が学べるのか、という実践的な問いへの、神経科学からの示唆でもあります。

ERP ── 脳波が捉える「和声の違反」

ERP（事象関連電位）は、刺激に対する脳波の微小な定型反応です。言語と音楽の統語処理で、対応する成分が知られています。

とりわけ ERAN（Early Right Anterior Negativity）は音楽統語の中心指標です。調性の期待に反する和音（例：ハ長調の流れに突然ナポリの和音）で早期の右前頭陰性が出る事で知られていて、これは聴き手が明示的な音楽訓練なしに和声の「文法」を内面化している証拠です。
ここで微分音への含意が生まれます。31edo の新しい和声語彙（中立和音や、ミーントーン以外の律射としての扱い）は、最初は「文法違反」として ERAN 的な反応を引くかもしれない。しかし言語の第二言語習得がそうであるように、曝露によって新しい統語が内面化されれば、違反反応は期待反応へと再編されると予測されます（Ⅵ-6 の第2層＝学習の話と接続）。

ERP が捉えるのは和声の統語だけではありません。音程そのものの処理にも使えます。
Ⅵ-5 でも扱ったBailes ら（2015）の研究は、12edo に馴染んだ聴き手にとって未知の微分音律が追加の処理負荷になるのか、そしてその知覚がどこまでボトムアップ（音響心理的・知覚的）で、どこからトップダウン（親近性・認知的）なのかを切り分けようとしました。音楽家10名・非音楽家10名に、12edo の協和音程・不協和音程・四分音の二音和音を提示し、ERP と主観評定（粗さ・好ましさ）を続けて記録しています。顕在的な評定と潜在的な脳波を突き合わせる設計です。

著者らは、音楽的専門性が四分音と 12edo 音程の感覚的・知覚的な弁別を促進し、それらをカテゴリーとして扱う能力を高めていると解釈しています。
非音楽家はそもそも両者をあまり区別していないということ。

これは ERAN の話とまったく同じ構図です。
訓練はカテゴリーを鋭くし、鋭いカテゴリーは境界の外にある音に厳しくなる。
言語で言えば、母語の音韻体系が確立しているほど、そこにない音素が既存のカテゴリーへ同化されやすくなるのと同型です（英語のlとrが日本語のラ行に同化するように）。微分音の実践者にとっては、聴き手の「耳が良い」ことが必ずしも味方ではない、という警告として読めます（Ⅵ-6 の第2層の議論と接続）。
同時に、ERP 振幅が協和音程で大きかったという第1層側の結果は、訓練の有無にかかわらず響きの区別自体は生じていることを示しており、二層モデルの構図が見事にここでも保たれています。

SSIRH ── 音楽と言語は文法資源を共有する

こうした ERP の蓄積が指し示す先が、音楽と言語の関係です。
Aniruddh Patel の SSIRH（Shared Syntactic Integration Resource Hypothesis、共有統語統合資源仮説、2003）は、こう主張します。音楽と言語は「記憶に貯えた要素」は別々（語彙と和音の知識は別の脳部位）だが、それらを構造へ統合する処理資源は共有している。文の途中で文法的に予想外の語が来たときと、和声進行で予想外の和音が来たときとで、同じ統合負荷が生じ、干渉しあうのです。実際、統語的に難しい文の処理中に音楽的に不協和な和音を聴かせると、両方の処理が悪化する、という行動・脳波実験が根拠です。

関連して 統語等価性仮説（SEH, Syntactic Equivalence Hypothesis）は、音楽と言語の統語処理の等価性をより強く見る立場で、両者の違反が共通の神経指標を引き出すことを重視します。これは Stefan Koelsch らを筆頭とする一連の ERP 研究の集大成という性格を持ちます。前節で見た ERAN・N5・P600 が言語の成分と対応することを、個別の実験としてではなく一つの理論的主張にまとめ上げたものです。いずれも「音楽の和声文法は、言語の文法と地続きの認知能力である」という方向を向いています。

生成文法と機能和声

音楽と言語の脳科学的関連は見ていきましたが、実際に音楽の統語を明示的に文法規則として書く試みも進んでいます。
Lerdahl & Jackendoff の GTTM（A Generative Theory of Tonal Music, 1983）は、Chomsky の生成文法に触発され、調性音楽を階層的な木構造（どの音がどの音に従属するかなど）として分析しました。機能和声の「T–S–D–T」（トニック→サブドミナント→ドミナント→トニック）は、この木の骨格であり、ドミナントはトニックへ解決するという強い従属関係を持ちます。近年は Rohrmeier の生成的和声文法など、文脈自由文法としてコード進行を生成・解析する形式化も現れています。

31edo の観点で面白いのは、この文法をそのままに、響きの層だけが組み変わることです。機能和声の木構造（従属・解決の関係）は保存したまま、各機能に割り当てる和音が 7-limit へ自然に差し替わり、本来なかった語彙の追加が含まれます。トライトーン代理に自然七和音（4:5:6:7）が運用出来たり、ブルーノートに対し中立和音を当てがったりすることができます。Ⅳ-6 で「増六＝7/4 は増六の文法の内側で運用される 7-limit 和音」と述べたのは、まさにこれでした。同じ文法で、和音の語彙を局所的に足し、類似のやや異なる音韻体系で話すことに近い。
つまり 31edo で書く調性音楽は、西洋音楽が訛った方言です。
初めて聞く方言でも文の構造は取れる。けれど母音がちょっと違う、抑揚がちょっと違う、と感じる。31edo の 386¢ の長3度が「低い」と感じられるのは、その種の違和感です。エンハーモニックの分離（C♯ と D♭ が別の音になる）も、方言が母語より細かい音韻対立を保存している、と読めます。

ところが、正則律射と MOS の側から音楽を組むとき、事情は変わります（Ⅴ部）。ポーキュパインやミラクルの音階は、全音階とも五度圏とも系譜を異にする骨格を持ち、そこに生成される和声進行はもはや西洋音楽の方言ではありません。聴き手は文法そのものを、聴きながらその場で推定することになる。認知の観点からは、これは人工言語で読み聞かせをされている状態に部分的に似ています。音素の体系も統語規則も一貫していて、内部的には完全に整合しているのに、聴き手の側にそれを解釈するための事前分布がない。ERAN が「違反」として反応するか「未知」として反応しないかも、この事前分布の有無にかかっています。

統語の骨格を保つ方言と、骨格から作り直す人工言語。31edo が珍しいのは、その両方を同じ鍵盤という音韻体系の上で提供できる点です。Ⅵ-6 でいう「第2層の流用」と「第2層の可塑性の行使」が、ここで具体的な二つの作曲の道として分かれます。

絶対音感 ── 音高に言語のようにラベルを貼る

最後に絶対音感（Absolute Pitch / AP）、基準音なしに音高の名前を言い当てる能力を、脳科学の側から扱います。
APは音楽と言語の接点として示唆的です。AP の獲得に必要な臨界期は、第一言語の習得の臨界期とほぼ重なる（幼少期の早期音楽訓練が要る）ことが知られ、AP 保持者は音高を音名という「語彙」のカテゴリーに変換して処理していると考えられます。

新潟大学脳研究所の伊藤浩介らは、この過程の神経指標を脳波で捉えました。
彼らの一連の研究（Itoh et al. 2005；Matsuda, Igarashi & Itoh 2019）は、高い AP 能力を持つ音楽家にのみ、音を聴いた約150ms 後に左後側頭部の陰性電位（「AP negativity」＝聴覚 T-complex の N1c 成分の左優位性）が現れることを示しました。
2019年の研究が明らかにした重要な点は、この左優位性が左半球の活動増強ではなく、右半球の N1c の減弱によって生じていることです。つまり AP 脳では、音高処理が言語的な左半球側へ非対称化している。つまり音高がほとんど「音の名前」という言語カテゴリーとして、早期かつ自動的に処理されているらしい。AP が「音を聴く」より「音を読む」に近い現象であることの、神経生理学的な裏づけです。

では、既に 12edo の AP を持つ人が、後天的に 31edo の AP を獲得することはありうるのか。この問いには公刊された実証研究がまだありません。そこで一つの事例報告として、念のため章末の余談で 31edo の AP を獲得した筆者自身の経過を扱っておきます。単一事例（n=1）ゆえの限界は大きいものの、AP のカテゴリーが臨界期の外でどう拡張されうるかについて、具体的な手がかりを含みます。

精密レイヤー ── 絶対音感と微分音、そして留保

AP と微分音の関係は両義的です。
難しさの側──
AP は12音のカテゴリーに強く調律された知覚です。31edo の音は 12edo のカテゴリーの「隙間」に落ちるため、AP 保持者はしばしば「どのカテゴリーにも属さない気持ち悪さ」を報告します。確立したカテゴリー境界が、新しい音の受容をむしろ妨げうる。これは AP がcategorical perception（カテゴリー知覚）であることの帰結で、言語で言えば母語にない音素を聞き分けにくいのと同型です。
可能性の側──
しかしカテゴリーは学習で作られたものである以上、原理的には31edo のカテゴリーを新たに獲得することもできるはずです（第二言語の音素獲得のように）。31edo の各音に音名（Ⅳ-5 の S–Z 体系）を与え、早期から曝露すれば、31edo の AP、「Eハーフシャープ」やエンハーモニックの差を直に同定する能力が育つ可能性は、上記の神経可塑性の知見と矛盾しません。実証研究はまだありませんが、微分音教育の長期的な問いとして魅力的です。

科学的な留保を明記します。
（1）伊藤浩介ら（2005年）の「AP negativity」は追試で再現しなかったとする報告（Leipold et al. 2019 ほか）もあり、成分の頑健性は議論が続いています。ただし続く2019年の T-complex 研究は方法を改善した上で左優位性を再確認しています。小サンプルの AP 研究一般に再現性の課題があることは念頭に置くべきです。
（2）SSIRH も、音楽と言語の共有の程度については議論があり、完全な共有から部分的重複まで幅があります。
（3）本節の「31edo の統語・カテゴリーは学習できる」という見通しは、Ⅵ-6 の二層モデルおよび神経可塑性からの合理的な推論であって、確立した実証ではありません。本書はこの推論に立って実践編（Ⅶ部）へ進みますが、それらが仮説であることは素直に示しておきます。

余談 ── 筆者の絶対音感

前項の「31edo の AP は後天的に獲得できるか」という問いについて、筆者自身の事例を報告します。以下は単一事例（n=1）の内観報告であり、公刊された実証研究ではありません。しかも後述のとおり、既存の 12edo AP という特殊な初期条件が効いているため、そのまま一般化はできません。その限界を承知のうえで、ひとつの手がかりとして記します。

～初期条件～
筆者は幼少期にピアノで遊ぶうちに 12edo の AP が付き、以降 12edo 上の音高を精確に同定できました。加えて中学生頃には、440 Hz と 442 Hz の順次提示（約 7.85¢ 差）を弁別できる程度の識別精度がありました。つまり「離散ピッチを基準なしにラベルへ写像する」認知装置と、「セント単位の細かな高低を分解する」精度とを、あらかじめ両方持っていたことになります。

～経過～
約5年前の2021年、西洋音楽の方言として（Ⅵ-6 の意味で）31edo の作曲（DTM）を始めました。鍛錬を積んだ結果、半年ほどで 31edo の音程同定が容易になりました。ただし極端に低い・高い音域を除きます。ここで重要なのは、変わったのが「弁別能力」ではないことです。7.85¢ を分ける精度は最初からあった。新しく獲得されたのは、その弁別に31edo という離散ラベルの体系を割り当てる写像のほうでした。第二言語の比喩で言えば、聞き分けられなかった音を聞けるようになったのではなく、既に聞き分けていた音に新しいラベル体系を貼れるようになった、という順序です。

～機構～
獲得された同定は、均等な31分類ではなく、12edo を根とする二段の決定木の形を取ったと認識しました。第一段でまず 12edo のクロマ（白鍵か黒鍵か）を確定し、第二段でそのカテゴリー内部を 31edo のマスへ細分します。筆者の内観は疑似コードで表すことができ、およそ次のようになります。

// 第一段：まず 12edo のクロマを確定（自動化済み・一瞬）
鍵盤の色 = (音高 が ド／レ／ミ／ファ／ソ／ラ／シ) ? "白" : "黒";

// 第二段：確定したカテゴリーの内部を 31edo へ細分
if (鍵盤の色 == "白") {
    if (中段)      臨時記号 = "ナチュラル";
    else if (上段)  臨時記号 = "ハーフシャープ";
    else            臨時記号 = "ハーフフラット";
} else {  // 黒鍵
    if (やや低い)   臨時記号 = "シャープ";
    else            臨時記号 = "フラット";
}

31edo の各音が独立したプリミティブとして立ち上がるのではなく、12edo のラベルを経由してアクセスされている点が特徴です。既に完全に自動化された 12edo の同定（親ノード）を捨てて建て直すのではなく、その内部を割る足場として再利用したかたちです。Ⅵ-6 で見た「31edo はミーントーンゆえ 12edo の第2層を流用できる」という利点が、AP の水準でも同じ構造で現れたことになります。

～時間発展～
この第二段の処理は、獲得当初から現在（約4年半）まで次第に変化してきました。初期には、確定した親カテゴリーを基準点に「そこからどちらへ、どれだけ」という相対音感的な計算が入っていました。現在は、その高低の弁別が記憶から直接立ち上がるようになり、同定が速くなっています。「白鍵/黒鍵」「段数」という下位カテゴリーのラベルが、計算の結果としてではなく想起の単位として定着しつつある。認知科学の言葉で言えば、手続き的な計算が反復により宣言的な想起へ移行する自動化（プロシージャライゼーション）の途上にあると解釈できます。決定木が消えたのではなく、決定木を辿った結果が複合ラベルとしてキャッシュされつつある、という感触です。

この見立てを支える非対称もあります。作曲で滅多に使わない音程（たとえば 19\31）は、いまもわずかに同定が遅い実感があります。使用頻度の高い音ほどキャッシュが厚く、低い音ほど初期の相対計算モードが残っています。頻度が語彙化を駆動していることの、主観的な証拠です。なお、実際にこの 31edo の同定を試みる様子は筆者の実演映像にあります。

含意と留保はもちろんします。
この事例が示唆するのは、AP のカテゴリーが臨界期の外でも、既存カテゴリーの細分化という経路で拡張されうる、ということです。これは近年の AP 研究、AP 保持者の音名カテゴリーが聴取経験で移動しうること、成人でも新規のピッチカテゴリー獲得がありうること、とも整合的です。ただし繰り返せば、これは n=1 の内観報告にすぎず、しかも既存の 12edo AP と 7.85¢ の弁別精度という、二つの完成した部品があった特殊事例です。ゼロから 31edo の絶対カテゴリーを建てねばならない非 AP 者には、そのまま当てはまりません。「AP がなくとも半年で 31edo AP が付く」とは、この事例からは極めて言い難いことを明記しておきます。

この節の要点 ERP：ERAN（和声違反の早期検出）・N400/N5（意味統合）・P600（再分析）が言語成分と対応。
SSIRH／SEH：音楽と言語は統語統合の資源を共有（要素は別、処理は共通）。
四分音 ERP（Bailes 2015）：ERP 振幅は協和音程で大きい一方、訓練された音楽家ほど四分音を強く嫌う。訓練はカテゴリーを鋭くし、境界の外に厳しくする。
GTTM／生成和声文法：機能和声＝階層木で、31edo は統語を保存したまま響きを差し替えられる。これは語彙の拡張というより西洋音楽の方言。対して正則律射・MOS から組む音楽は骨格から異なり、聴き手に事前分布のない人工言語の読み聞かせに近い。
絶対音感：音高を言語カテゴリー化する能力で、臨界期が第一言語と重なり、新潟大の研究は左優位の N1c（右半球減弱による）を指標として示す。12edo のカテゴリーは 31edo の受容を妨げうるが、31edo のカテゴリー獲得も原理的に可能。

これで第Ⅵ部「響きの科学」を終えます。物理から数理、知覚、そして脳まで、31edo が「なぜ良い響きを持つのか」を多層的に見てきました。残るは、これらを実際に音楽にする技術です。第Ⅶ部 に続きます。
