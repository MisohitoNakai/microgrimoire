微分音のグリモワール 第Ⅱ部 純正律とその格子

第Ⅱ部 純正律とその格子　─　4

そのほかのコンマ ── 種族の肖像画

直感レイヤー

シントニックコンマは氷山の一角です。
格子の上で「もう少しで一致するのに、しない」場所の数だけコンマがあり、それぞれに名前と性格があります。そして面白いのはここからで、どのコンマを「無いこと」にするかは、音律ごとに違います。
12平均律はシントニックコンマも小ディエシスも消すので G♯ と A♭ が同じ鍵へ。31平均律は小ディエシスを消さないので G♯ と A♭ が別の音として残る。コンマの目録は、そのまま音律たちの個性の目録なのです。

コンマ目録

本書で以後登場する主要なコンマを一覧にします。「12edo」「31edo」の列は、そのコンマが各音律で何ステップに写るかを示しています。
0 なら「その音律はこのコンマを消している（テンパーアウト）」、±1 以上なら「区別が生き残っている」。それらをその場で計算した値です（計算規則は下の精密レイヤー）。♪ は試聴で、モードを選べます。

コンマを聴く

基音 440 Hz。小さいコンマは「同時」でうなりとして聴くのが確実です（Ⅰ-5）。

目録の読みどころ

ピタゴラスコンマ（23.46¢）——5度を12回積むと7オクターブを僅かに超える、3-limit 最古のコンマ。12edo はこれを消すことで「5度圏が閉じる」音律になっています。31edo では補正が強すぎて逆転します（−1 ステップ）。したがって、31edo の5度圏は 12 回では閉じず、31 回で初めて閉じます。

小ディエシス 128/125（41.06¢）——長3度を3回積んだ音とオクターブの差。12edo はこれを消すので、C–E–G♯–B♯ の B♯ が C に戻り、G♯＝A♭ という異名同音が成立します。31edo では 1 ステップ（38.7¢——ディエシスの実測値に肉薄！）として生き残り、G♯ と A♭ は別の鍵・別の響きになります。31edo の鍵盤に「黒鍵が割れている」見た目の理由がこれです（第Ⅳ部5）。

septimal comma 64/63（27.26¢）——3の道の短7度 16/9 と自然7度 7/4 の差。12edo はこれを消すため、属七の第7音が「7/4 のつもり」と「16/9 のつもり」を兼任させられ、中途半端になります。31edo では 1 ステップとして区別され、「短7度」と「自然7度」を弾き分けられます。

marvel comma 225/224（7.71¢）——5-limit の 225/128 と 7/4 の橋渡し。これを消すと、5-limit の語彙から 7-limit の響きへ滑らかに乗り換えられます。12edo も 31edo も消しており、31edo の 7-limit の増六の和音の強さの一因です。

gamelisma 1029/1024（8.43¢）——8/7 を3回積むと 3/2 との間に残る端数。これを消すと「8/7 三つ＝3/2」というバリ島のガムラン的な骨格（Slendric、第Ⅴ部3）が生まれます。31edo はこれを消す音律のひとつで、31 の多面性（第Ⅳ部2）の一枚です。

rastma 243/242（7.14¢）——中立3度 11/9 を2回積むと 3/2 との間に残る端数。消せば「中立3度ふたつ＝完全5度」（Rastmic）。これも 31edo が消すコンマで、31edo のもうひとつの顔です。

スキスマ 32805/32768（1.95¢）——シントニックコンマとピタゴラスコンマの差にあたる極めて小さいコンマ。人間の順次 JND を下回る音程で、これを消す Schismatic 系（第Ⅴ部3・53edo など）は 5-limit をほぼ純正のまま扱えます。12edo は消しますが、31edo は消せません。ミーントーンとスキスマティックは 5 への到達経路が正反対（5度を狭める vs ほぼ純正に保つ）の好対照です。

精密レイヤー ── ステップ数の計算規則（val の先取り）

表の「12edo / 31edo」列は次の規則で計算しています。n-edo は各素数 \(p\) を「最寄りのステップ数」 \(v_p = \operatorname{round}(n \log_2 p)\) に写します。
12edo なら \( (v_2, v_3, v_5, v_7, v_{11}, v_{13}) = (12, 19, 28, 34, 42, 44) \)、
31edo なら \( (31, 49, 72, 87, 107, 115) \)。
コンマ \( 2^{e_2} \times 3^{e_3} \times 5^{e_5} \cdots \) の写り先は内積 \( \sum_p e_p v_p \) ステップです。
この「素数→ステップ数」の対応表こそ、第Ⅲ部で val ⟨12 19 28 …] と呼んで主役に据えるものです。そして「コンマが 0 ステップに写る」＝「その音律がコンマをテンパーアウトしている」という言い換えが、Regular Temperament 理論の入口の定義になります。ここでは patent val（各素数を独立に最良近似する val）のみを使っています。同じ n でも別の val を選ぶ流儀があること、その意味は第Ⅲ部で扱います。

もう一点、表の因数分解の指数の並び \((e_2, e_3, e_5, \dots)\) をそのまま縦に書いたものが monzo です。すなわち本節の表は、次章の言語（monzo と val の内積）を、名前を伏せてすでに運用しています。

コンマ目録＝音律の設計空間

目録を眺めると、コンマには二つの顔があることが分かります。
ひとつは障害物としての顔：ポンプでピッチを引きずり、鍵盤の在庫を圧迫する。
もうひとつは資源としての顔：どれを消すかの選択が、そのまま音組織の個性になる。
81/80 を消せばミーントーンの世界、
32805/32768 を消せばスキスマティックの世界、
1029/1024 を消せばslendricの世界。
そして複数のコンマを同時に消すと何が起こるか？
たとえば 81/80 と 393216/390625 を両方消すと？
（答えは31edo になります。理由は次節と第Ⅲ部3で。）

この節の要点 コンマは多数多様。各音律は「どのコンマを 0 に写すか」で個性が決まる。12edo はピタゴラスコンマ・小ディエシス・64/63 などを消し、31edo はそれらを保存しつつ 81/80・225/224・1029/1024・243/242 を消す。コンマの選択＝音律の設計。
